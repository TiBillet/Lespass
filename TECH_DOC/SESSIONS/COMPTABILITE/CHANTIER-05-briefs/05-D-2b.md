   `MembershipMVT.ajouter_paiement` ~l.4701-4794) : ligne, vente (`ADMIN`) et encaissement
   dans **un** `atomic` ; la ligne passe `PAID` (déclencheur `trigger_A`) **puis** la vente
   est encaissée ; encaissée **même si** `trigger_A` échoue (l'argent est déclaré reçu) ;
   un règlement au moyen choisi.

   FREE ne vaut que 0 (vente à 0, aucun règlement).

   ~l.1342-1347) : une contribution > 0 **sans** moyen de paiement est refusée, message
