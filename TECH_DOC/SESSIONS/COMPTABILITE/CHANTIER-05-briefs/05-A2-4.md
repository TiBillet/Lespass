## Particularité de A′ : pas de rouge
Un test de caractérisation fige le comportement **actuel** : il est **vert** sur le code
actuel. Sa force est prouvée par les **mutations** que l'orchestrateur joue ensuite.
**Tu ne modifies aucun code de production.** Si un comportement te semble faux : tu le
figes tel quel, tu écris dans le docstring « comportement actuel figé (voir T… ) » et
tu le signales au rapport. Les tests qui changeront en D / G / H (fiche §4) figent eux
aussi le comportement **actuel** ; leur docstring le dit (« change en D, décision
D30 », etc.).
