## Pourquoi
À la session suivante (D-1c), chaque paiement Stripe de test sera **encaissé** : sa vente
devient scellée, et un règlement protège le paiement (`Reglement.paiement_stripe` en
`PROTECT`, `BaseBillet/models_vente.py`). Les nettoyages de fin de test qui suppriment
paiements, lignes ou réservations lèveront alors `ProtectedError`.
**Décision du mainteneur** : on ne fait plus le ménage. Les tests Stripe laissent leurs
vraies données en base de dev (elle peut grossir) ; on **archive seulement les
événements** qu'ils créent (`Event.archived = True`), pour ne pas remplir l'agenda
(bug n°18 du TODO).
