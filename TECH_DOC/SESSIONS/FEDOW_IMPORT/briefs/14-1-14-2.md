## Étapes (pour chaque session, 14-1 puis 14-2)
1. **Rouge** : écris le test et vois-le échouer pour la bonne raison SANS toucher au code de production :
   par exemple, lance-le avec une précondition volontairement fausse dans le TEST lui-même (moteur
   attendu inversé, montant attendu faux, asset attendu absent), colle la sortie, puis remets la bonne
   précondition. Dis exactement ce que tu as inversé.
2. **Vert** : lance-le seul, colle la sortie. Lance-le une seconde fois pour vérifier qu'il est rejouable
   (noms uniques, rien qui bloque un second lancement).
3. **Mutations LISTÉES** (fichier de production:ligne, 2 à 4 par test : par exemple garde du verrou
   retirée pour l'autocomplétion, signal d'archivage du produit retiré, ventilation lue sur le mauvais
   lieu) : l'orchestrateur les joue.
4. **Ce qui a été écrit sur le Fedow de dev** (assets, fédérations, portefeuilles, transactions), en
   une liste courte.
5. CHANGELOG `CHANGELOG/2026-10-06-tests-federation-inter-lieux.md` (FR puis EN), section par session.
Après 14-1 : rapport, puis STOP (l'orchestrateur joue les mutations et te relance pour 14-2).
