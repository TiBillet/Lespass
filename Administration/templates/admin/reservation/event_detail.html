GET /event//admin_show_event_detail/ (EventMVT.admin_show_event_detail, BaseBillet/views.py) 3. La vue rend la page complète. Le bouton « retour » du navigateur fonctionne. FLUX DES FILTRES : 1. On tape dans un champ ou on choisit une option (événement « input ») 2. Après 400 ms, HTMX rappelle la même vue avec les filtres en GET 3. La vue voit l'en-tête HX-Target = "event-detail-results" et ne renvoie que partials/event_detail_results.html 4. HTMX remplace #event-detail-results. Le reste de la page ne bouge pas. 5. hx-replace-url met les filtres dans l'adresse de la page. Après un clic sur un billet, le bouton « retour » ramène à la fiche AVEC les mêmes filtres. « Réinitialiser » est un lien classique : il recharge la fiche sans filtre. Les filtres ne sont PAS les filtres natifs d'Unfold (unfold.contrib.filters) : ceux-ci ne marchent que dans la liste d'un ModelAdmin. Ici, c'est un formulaire HTMX qui reprend les classes CSS des champs d'Unfold (unfold_input_classes, unfold_select_classes).
